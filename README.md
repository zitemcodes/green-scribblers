# Green Scribblers

The website for Green Scribblers, the stationery company I started in 2024. We sell recycled pencils and give one pencil to a pupil at a school that needs them for every pencil sold.

**See it here:** https://zitemcodes.github.io/green-scribblers/

## What it does

Five pages that all link to each other: a home page with the banner and my CEO message, an About page with our mission and vision, a Pencil Pals page showing eight pencils you can buy, a Contact page with a form, and a Stationery page that is still under construction.

## How I built it

Plain HTML and CSS, written by hand. No frameworks and no templates. Every page has its own stylesheet.
